## v1 リリース基準（仕様書 18 より）

- [ ] 入力画像を読み込み、`1920x1080` に cover resize + center crop できる
- [ ] 正規化済み画像をベースに 2〜5 枚のフレームを生成できる
- [ ] 生成される全フレームが `1920x1080` で出力される
- [ ] 中心点を自動または手動で指定できる
- [ ] 少なくとも集中線、衝撃波、フラッシュ系のプリセットを生成できる
- [ ] PNG または WebP で保存できる
- [ ] 複数フレームを ZIP で保存できる
- [ ] 画像をサーバーへ送信しない
